## Current status

The project foundation is in place:

- Astro is installed and configured
- Tailwind CSS is wired through Vite
- Prettier is available for formatting
- Astro diagnostics are available through `@astrojs/check`
- a reusable base layout exists
- the homepage has a responsive SaaS-style shell
- the `/demo-report` showcase has two static variants driven by local structured data
- the docs system now includes a project brief and prompt log

Use the other files in this folder as the project evolves.
